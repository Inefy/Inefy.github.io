About

A practical developer with a bias toward usable demos.

I am Zac Batten, a software developer who likes building practical tools that make messy workflows feel smaller: web apps for field work, Python automation for streams, frontend interfaces that explain themselves, maps that help people act, and browser experiments that stay useful. Right now I am focused on sharper frontend patterns, resilient JavaScript, Python integrations, and map-based interfaces that can be demonstrated clearly in public. My strongest fit is work where a team needs someone who can turn repeated manual steps into a working demo, then keep improving the interface until it is easier to understand and harder to break. I value clarity, working demos, resilience, and usability, so this portfolio favors live projects, accessible paths, and proof over vague project names.

Case study

Public repo / live showcase

MovieBot reduces the manual work behind Twitch movie nights.

MovieBot is a Python Twitch bot that turns chat commands into a watch-party queue. It tracks votes, handles stream-room commands, refreshes tokens, and hands the winning local media file to OBS.

Open Movie Night View source
Python TwitchIO OBS WebSocket OAuth refresh Static showcase
Problem

Manual stream chores

Movie voting, queue checks, result tallying, and media-source swaps created too much host overhead during a live watch party.

Constraints

Local files, public chat

The bot needs to respect the local movie folder, survive long sessions, validate chat commands, and recover cleanly from Twitch or OBS connection trouble.

Role

Built end to end

I built the vote commands, result handling, token refresh, OBS handoff, static movie pages, and searchable public-domain library.

Next

Better operator view

The next useful pass is a small control/status panel for queue state, current votes, OBS connection health, and upcoming media.

Case study

Live browser tool

Web Paint turns a familiar desktop workflow into a browser tool.

Web Paint is a no-build canvas app with drawing tools, shape controls, undo/redo, zoom, local save/load, and PNG export in a responsive Paint-style interface.

Open Web Paint View source
Canvas API Pointer events LocalStorage PNG export Responsive UI
Problem

Useful drawing needs predictable controls

A browser sketch tool has to preserve familiar Paint affordances while keeping the canvas state reliable across undo, redo, resizing, and export.

Constraints

No framework, still tool-like

The UI uses static HTML, CSS, and JavaScript, so the tool state, pointer handling, responsive ribbon, and file export all live in focused browser code.

Role

Built the full interaction model

I built the drawing engine, tool switching, brush and shape controls, local save/load, zoom behavior, canvas resizing, and PNG export path.

Next

More precision tools

The next useful pass would add selection movement, richer keyboard shortcuts, and cleaner layer-like workflows without making the app heavy.

Current rule

Make the useful version first. Make it pretty after it survives real use.
