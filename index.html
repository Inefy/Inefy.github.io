TraverseOps makes field operations map-first.

Problem: Field crews lose time when maps, asset records, inspections, and work orders live in separate tools.

Solution: TraverseOps brings asset lookup, field context, inspection notes, and work-order flow into one map workspace for desktop review and mobile field use.

Case study

Public repo / live showcase

MovieBot reduces the manual work behind Twitch movie nights.

Twitch movie nights can bog down in manual polling and OBS setup, so I built a Python/TwitchIO bot that turns chat commands into vote state, handles changed votes and ties, scans local public-domain movies, refreshes tokens, reconnects when needed, and hands the winner to OBS through WebSocket.

Open Movie Night View source Full case study
Python TwitchIO OBS WebSocket OAuth refresh Static showcase
Problem

Manual stream chores

Movie voting, queue checks, result tallying, and media-source swaps created too much host overhead during a live watch party.

Constraints

Local files, public chat

The bot needs to respect the local movie folder, survive long sessions, validate chat commands, and recover cleanly from Twitch or OBS connection trouble.

Role

Built end to end

I built the vote commands, result handling, token refresh, OBS handoff, static movie pages, and searchable public-domain library.

Next

Better operator view

The next implementation pass is an operator control/status panel for queue state, current votes, OBS connection health, and upcoming media.

Case study

Live browser tool

Web Paint turns a familiar desktop workflow into a browser tool.

Browser drawing tools become frustrating when tool state, history, imports, and resizing are unreliable. I built Web Paint as a no-build HTML/CSS/JavaScript Canvas editor with drawing modes, typed-array flood fill, capped undo/redo snapshots, PNG import/export, local save/load, zoom, fullscreen, and mobile-friendly tool panels.

Open Web Paint View source Full case study
Canvas API Pointer events LocalStorage PNG export Mobile tool UI
Problem

Drawing workflows need predictable controls

A browser sketch tool has to preserve familiar Paint affordances while keeping the canvas state reliable across undo, redo, resizing, and export.

Constraints

No framework, still tool-like

The UI uses static HTML, CSS, and JavaScript, so the tool state, pointer handling, narrow-screen ribbon, and file export all live in focused browser code.

Role

Built the full interaction model

I built the drawing engine, tool switching, brush and shape controls, local save/load, zoom behavior, canvas resizing, and PNG export path.

Next

More precision tools

The next implementation pass would add selection movement, richer keyboard shortcuts, and layer-style workflows without making the app heavy.

Current rule

Ship the working version first. Refine the interface after it survives real use.
