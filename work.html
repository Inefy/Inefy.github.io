Technical care in the site.

GitHub Pages structure

Hosting

No-JS fallbacks
Key pages keep HTML fallback content.
Security headers
CSP meta tags limit scripts, styles, images, frames, media, and workers.
Review experience

Built for sharing and scanning.

Metadata
Major pages include titles, descriptions, previews, sitemap entries, and context.
Media loading
Screenshots and posters use lazy loading, dimensions, and reserved boxes.
Accessibility
Skip links, focus states, keyboard paths, labels, status, and reduced motion.
