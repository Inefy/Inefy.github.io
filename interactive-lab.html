Canvas tool

Web Paint

Paint-style browser drawing app with tools, color controls, undo/redo, zoom, local save/load, and PNG export.

Demonstrates
Canvas state, pointer events, responsive toolbar UI, and client-side export.
Controls
Mouse, touch, swatches, sliders, toolbar buttons, and file actions.

Physics game

Mini Golf

Five-hole browser golf game with aiming, shot power, collisions, hazards, sand traps, and saved best scores.

Demonstrates
Canvas physics, level state, collision handling, and local persistence.
Controls
Drag to aim and set power, release to shoot, then advance hole-by-hole.
