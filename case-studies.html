Flagship / public demo

TraverseOps

Problem
Field crews lose time when maps, asset records, inspections, and work orders live in separate tools.
What Zac built
A map-first field operations demo with asset lookup, selected-asset context, inspection notes, and work-order flow.
Tech stack
MapLibre, Supabase-backed sample data, responsive frontend, Capacitor-ready app structure.
Main technical challenge
Keeping dense map, record, and workflow UI understandable on both desktop review screens and mobile field contexts.

Automation / public repo

MovieBot / StreamCinema Vote Bot

Problem
Hosted Twitch movie nights need voting, result tallying, queue state, and OBS playback without constant manual control.
What Zac built
A Python Twitch bot that listens to chat commands, tracks votes, refreshes OAuth tokens, and hands the selected local media file to OBS.
Tech stack
Python, TwitchIO, Twitch IRC/chat commands, OAuth refresh, OBS WebSocket, static showcase pages.
Main technical challenge
Making a long-running stream tool resilient across Twitch auth, chat connection health, local file state, and OBS handoff timing.

Canvas tool / live demo

Web Paint

Problem
A useful browser drawing tool needs familiar controls, reliable canvas state, and export behavior without a heavy framework.
What Zac built
A Paint-style app with drawing tools, shapes, eraser, fill, undo/redo, zoom, local save/load, canvas resizing, and PNG export.
Tech stack
HTML Canvas, vanilla JavaScript, pointer events, CSS Grid, LocalStorage, File APIs.
Main technical challenge
Keeping tool state, canvas history, resizing, zoom, and export predictable while the UI stays responsive.
Full case study Live demo GitHub
Companion app / static UI

Public Domain Movie Library

Problem
The live Movie Night page should stay focused on watching and voting, while viewers still need a fast way to browse the full queue.
What Zac built
A companion library page with poster cards, search/filter behavior, queue metadata, copyable vote actions, and a no-JavaScript fallback list.
Tech stack
Static HTML, CSS Grid, vanilla JavaScript search, movie metadata, external poster images, no-JavaScript fallback markup.
Main technical challenge
Keeping a large static movie list usable and indexable while preserving a clean fallback when JavaScript or external posters are unavailable.
