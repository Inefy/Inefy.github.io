Bot at work

How StreamCinema Vote Bot runs the night.

Streamer-run public-domain movie nights need reliable voting and playback handoff. I built the Python/TwitchIO bot to scan local video files, listen to chat commands, count and resolve votes, refresh/reconnect when services drift, and tell OBS WebSocket which file to play next.

What I built

Viewer-facing stream page and bot explanation surface.

  • Created the static stream room that embeds the Twitch player/chat and keeps movie-library, bot-source, and case-study paths close to the voting experience.
  • Added embed fallbacks and external links so the page still gives viewers a clear path when Twitch embeds are blocked.
  • Separated the searchable movie catalog into its own page so the live-room UI stays focused on watching and voting.
  • Wrote the bot-flow explanation that connects local folder scanning, chat commands, tie resolution, token refresh/reconnect behavior, and OBS playback handoff.

The page depends on Twitch embeds, Twitch chat, OBS WebSocket, and public-domain movie data; the static site structure, copy, and MovieBot presentation are custom portfolio code.

Production readiness

A useful showcase surface, not the production bot runtime.

  • Already solid: static stream-room layout, Twitch embed fallbacks, clear Movie Library and source links, and a concise explanation of the bot workflow.
  • Demo-only: the page shows the voting system and bot story, while actual playback still depends on the local Python bot, OBS setup, and stream operator.
  • Hardening needed: operator status panels, embed-health messaging, live bot connection state, queue visibility, and stronger checks around Twitch/OBS availability.
  • Security/privacy/ops: keep OAuth/OBS secrets out of the page, rely on Twitch moderation for chat, and avoid exposing local media paths or private stream configuration.
Testing and QA notes

The stream page needs both embed checks and bot-flow validation.

  • Automated tests: the Python bot repo has pytest coverage for core automation paths; this static showcase page is currently validated with manual/browser smoke checks.
  • Manual checklist: verify Twitch player/chat embeds, blocked-embed fallback links, Movie Library and GitHub links, bot-flow explanation, contact paths, and keyboard focus through the page.
  • Browser/device checks: test desktop, tablet, and narrow mobile layouts, including whether the stream/chat embed area stays readable and fallback actions remain easy to tap.
  • Edge cases: Twitch embeds blocked by privacy settings, offline stream state, chat unavailable, slow poster loading in the linked library, and unavailable clipboard permissions for vote commands.
  • Known limitations: the page does not show live bot health, current queue state, OBS connection status, or real-time operator alerts yet.
Deployment and run notes

The showcase is static; the live automation runs in the local bot.

  • Hosted/run location: this page is served by GitHub Pages at zacbatten.me/movie-night.html; the Python bot runs separately on the stream operator's machine.
  • Environment/config: the page has no secrets or environment variables. Twitch channel names are constrained in the embed script, and local development is included in the allowed Twitch parent list.
  • External APIs/services: Twitch player/chat embeds are lazy-loaded on request, while Movie Library, GitHub, and case-study links provide the support paths around the stream.
  • Local development: run python -m http.server 8000 from the portfolio repo root and open /movie-night.html; use the fallback links if Twitch embeds are blocked on localhost or by browser privacy settings.
  • Secrets/security: Twitch OAuth tokens, OBS passwords, local movie paths, and bot logs belong only in the bot runtime, never in this static page or client-side JavaScript.

OBS WebSocket updates the media source, switches to the configured scene, and starts the selected movie.

Long stream details

The bot is built for long sessions: it refreshes Twitch OAuth tokens, watches the Twitch chat connection, and reconnects to OBS when needed.
